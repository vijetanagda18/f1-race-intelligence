# 🏎️ Formula 1 Race Intelligence

An interactive Formula 1 dashboard built using Tableau Public and Flask to explore race results, driver performance, team trends, and race reliability.

## ✨ Key Features

- Interactive Formula 1 race intelligence dashboard
- Race results and performance analysis
- Driver and team performance trends
- DNF (Did Not Finish) analysis
- Interactive dashboard filters
- Tableau dashboard and story integration
- Flask-based web interface

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- Tableau Public
- Gunicorn
- Render

## 📊 Project Overview

Formula 1 Race Intelligence provides an interactive visual exploration of Formula 1 racing data. It helps users understand race outcomes, driver performance, team trends, and reliability through Tableau visualizations embedded in a Flask web application.

The project combines data visualization with web development to make motorsport insights accessible through a web browser.

## ⚙️ How to Run Locally

### 1. Clone the Repository

```bash
git clone https://github.com/vijetanagda18/f1-race-intelligence.git
```

### 2. Open the Project Folder

```bash
cd f1-race-intelligence
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Flask Application

```bash
python app.py
```

### 5. Open the Website

Open the following address in your browser:

http://127.0.0.1:5000
